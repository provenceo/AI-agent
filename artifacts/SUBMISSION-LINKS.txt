终端完整日志见同目录：cli-demo-output.txt（生成命令：npm run demo:all）

新增可交互业务（Vue 预览页）：
- 运行「审批流执行」：选择角色，点保存/提交/审批通过/驳回，状态与表单会联动并持久化到 localStorage
- 表单字段会根据 Schema 自动渲染（字符串/数字/数组字段）
- 由 Node 侧生成「钉钉审批流结构树」并在页面展示

录屏 / 截图建议：本地执行 `npm run dev`，切换到「审批/表单」->「运行流水线」-> 编辑表单 -> 依次点「提交/审批通过/驳回」，再切换「智能播放」「性能治理」各点一次「推断/扫描」。
